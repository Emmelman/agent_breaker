# Сертификаты GigaChat (mTLS)

Для подключения к GigaChat в банковском контуре сюда нужно положить
клиентские сертификаты:

- `client_cert.pem` — клиентский сертификат
- `client_key.pem` — приватный ключ клиента

Пути настраиваются в [`v2/config.yaml`](../config.yaml) — поля
`llm.cert_path` и `llm.key_path` (по умолчанию указывают на эту папку).

## Безопасность

`client_key.pem` — **приватный ключ**. Файлы сертификатов:

- кладутся в эту папку **вручную** на машине банковского контура;
- **исключены из git** (см. корневой `.gitignore`: `v2/certs/`, `*.pem`);
- **никогда** не коммитятся в репозиторий.

В git попадает только этот README.
